# Icône KubeClean — modèle 13

Choix de l’utilisateur : 13 de la planche « Variations du concept 02 · Noir & blanc ».
Génération avec l’outil intégré imagegen, puis déclinaisons PNG et ICO via `npm run icon`.
Le script pose le motif détouré sur une tuile blanche uniforme, puis normalise son
contour avec un masque géométrique. Il vérifie aussi que le centre est blanc et opaque.

Source : `icon-master.png`, 1254 × 1254 pixels. Le motif représente un anneau de
stockage métallique en trois segments, ouvert en haut à droite, avec une flèche
orientée vers l’extérieur. Le fond de la source est transparent ; la tuile blanche
est ajoutée à l’export. L’ensemble reste exclusivement en niveaux de gris.
