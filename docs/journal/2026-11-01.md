# 2026-11-01

## Summary
Rétro-ingénierie d'AVG TuneUp (règles gf2engine embarquées dans `TuneupSvc.exe`), puis KubeClean en trois temps : v1 Node.js + page locale (`legacy/`), v2 moteur Rust + Electron + Svelte 5 sur le kit Kube, puis refonte « premium » de l'interface par orchestration de sous-agents (4 bâtisseurs, 1 revue design). Installeur Windows ARM64 construit.

## Added
- `core/` : moteur Rust `kubeclean-core.exe`, JSON lines sur stdin/stdout, événements `progress` et `rule` en direct pendant l'analyse.
- `core/rules/default.json` : règles de nettoyage (caches, temporaires, dossiers de compilation, gros fichiers, téléchargements).
- `app/electron/main.mjs`, `app/electron/preload.cjs` : fenêtre, protocole `app://kubeclean`, pont IPC à liste blanche, confirmation de fermeture pendant un nettoyage.
- `app/src/` : vues Dashboard, Clean, Projects, Files, History, Settings, Result, Running, Confirm, RulePanel, Palette (Ctrl K) ; état partagé `app/src/lib/state.svelte.js`.
- `app/scripts/mock-core.mjs` : moteur factice (KC_MOCK=1), aucun accès disque.
- `app/scripts/shot.mjs` : harnais de captures ; KC_REAL=1 analyse seule, `doclean` refusé.
- `app/scripts/make-icon.mjs`, `app/build/icon.png`, `app/public/icon.png` : icône.
- `app/docs/BRIEF.md`, `app/docs/kube.md`, `app/docs/REVIEW.md` : direction de design, inventaire du kit, revue design (44 constats).
- `app/release/KubeClean Setup 2.0.0.exe` : installeur NSIS arm64, 110 Mo, non signé (hors dépôt).

## Modified
- `README.md` : fonctionnalités, flux de dev (KC_MOCK, shot.mjs, KC_REAL), sécurité.
- `core/src/scan.rs` : `supersededOnly` (anciennes versions JetBrains / Android Studio), exclusions OneDrive/Downloads des gros fichiers.

- `app/scripts/shot.mjs` : étape `clean` renommée `doclean` (collision avec la vue `clean`) ; attente d'analyse 300 s en moteur réel.
- Réglages : brouillon suit `S.settings` (v1 figeait l'état avant la réponse du moteur).

## Discoveries
- Electron 44 ne télécharge plus son binaire à `npm install` : `"postinstall": "install-electron"` (→ user LES-20261101-001).
- Deux harnais de capture Electron simultanés donnent des captures délavées ou vides ; relancer seul avant de conclure (→ user LES-20261101-002).
- Electron 44.9.0 portait un avis de sécurité élevé : épinglé 44.9.3. (non retenu)
- Svelte 5 rogne l'espace avant « · » en fin de ligne de gabarit : écrire `{' · '}`. (non retenu)
- Analyse réelle jusqu'à 80 s sous charge sur cette machine (Windows 11 ARM64), 27,4 Go trouvés dont 1,4 Go cochés d'office ; rien nettoyé. (non retenu)
- Installeur non signé : SmartScreen demande « Informations complémentaires → Exécuter quand même ». (non retenu)
- PowerShell 5.1 affiche en rouge (NativeCommandError) la progression de `git push` écrite sur stderr ; le push a réussi. (non retenu)

## Decisions
- Pile : Rust pour tout le back-end, Electron + Svelte 5 + Vite pour le front, kit Kube (`G:\KUBE_style`) copié dans `app/public/kube/`.
- Aucun nettoyage réel n'est jamais lancé par un outil de dev : moteur factice pour l'UI, `doclean` refusé en KC_REAL.
- Fichiers personnels jamais cochés d'office, envoyés à la Corbeille ; tâches admin par UAC sur liste fermée.
