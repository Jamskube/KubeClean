## Discoveries
- `webContents.capturePage()` ne rend pas le Mica : en sombre, le chrome transparent paraît cassé sur la capture alors que la fenêtre réelle est correcte ; vérifier par une capture d'écran réelle (→ user LES-20261102-001).
- PowerShell passe `$null` à un paramètre `string` P/Invoke comme chaîne vide : `FindWindow($null, titre)` ne trouve rien ; prendre `(Get-Process).MainWindowHandle` (→ user LES-20261102-002).
- PowerShell : noms de variables insensibles à la casse, `$S` et `$s` sont la même variable. (non retenu)
- Un sous-agent a signalé une espace manquante avant « : » déjà insécable (octets `302 240`) : vérifier au niveau de l'octet avant d'éditer. (non retenu)
- Un gain disque négatif (le disque s'est rempli pendant le nettoyage) s'affiche « 0 Go ». (non retenu)
- Le premier essai « liquid glass » coloré a été jugé cliché par l'utilisateur : préférer le verre neutre, sans couleur décorative. (non retenu, préférence du projet)
- Gotcha · `app/src/RailPreview.svelte` : un ancêtre transformé peut décaler un élément fixed ; placer les aperçus hors de cet ancêtre ou dans la top layer. Journal uniquement, ajout à AGENTS.md refusé par l’utilisateur.
- Warning · `app/scripts/shot.mjs` : un seul harnais Electron à la fois évite les interférences entre fenêtres ; mémoire approuvée.
- Workaround · `app/scripts/make-icon.mjs` : détourage du métal puis recomposition sur blanc pour supprimer la tache persistante ; contrôler les pixels centraux à l’export. Mémoire approuvée.
- `app/src/app.css` : le sticky hérite sinon de la largeur de la colonne centrée ; un conteneur de largeur sur la zone de défilement permet de couvrir le panneau sans désaligner son contenu.
